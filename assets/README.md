# assets/

Optional. Save the official TMDB logo here as `tmdb-logo.svg`
(download it from <https://www.themoviedb.org/about/logos-attribution>).

CineFloat shows the logo hosted by TMDB first. If that cannot be loaded (for example
when you are offline) it tries `assets/tmdb-logo.svg`, and finally falls back to the
plain text "TMDB". The attribution sentence next to it is always shown.
