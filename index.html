    About and credits

    CineFloat is a floating-poster movie browser made with vanilla HTML, CSS and JavaScript, packaged with Electron.

    This product uses the TMDB API but is not endorsed or certified by TMDB.

    Movie data and images are provided by TMDB. Streaming availability data is provided by JustWatch.

    Gestures

    Click a poster to open it. Drag one (or press and hold on touch screens) to throw it, and drop it on Watchlist or Favorites to save it. Drag or swipe the rows; use Shift + mouse wheel for sideways scrolling.

    Add your TMDB token

    CineFloat needs a free TMDB API Read Access Token.

    1. Create a free account and open themoviedb.org → Settings → API.
    2. Copy the long API Read Access Token (it starts with eyJ).
    3. Copy config.example.js to config.js and paste the token inside.
    4. Reload this page (or restart the app).
